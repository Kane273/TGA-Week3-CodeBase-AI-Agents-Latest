        Privacy and data controls

        Server persistence

        Research questions, graph checkpoints, protocol artifacts, approval decisions, and audit events are stored in the configured SQLite or PostgreSQL database and associated with your user ID.

        Browser-only data

        Theme, view role, bookmarks, saved filters, comments, inbox activity, interaction analytics, and usability feedback remain in this browser's local storage.

        Voice processing

        Without provider keys, recording and dictation use browser speech services. Audio is not uploaded or saved by ResearchGuard. ElevenLabs receives audio only when server-side voice features are configured and explicitly used.

        External services

        In live mode, configured language-model providers receive agent prompts. PubMed and Crossref receive evidence queries. LangSmith receives traces only when tracing is enabled.

        Retention and deletion

        Runs remain until archived, deleted, or removed by configured retention cleanup. Resetting the workspace deletes server runs for the current user. The browser-data control below removes local preferences and review metadata.

        Do not submit sensitive participant data. ResearchGuard is designed for research planning, not storage of protected health information or identifiable study records.
